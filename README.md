# InvestRent Website

Strona internetowa biura nieruchomości InvestRent w Kołobrzegu.

## Stack

- **Framework:** Next.js 14
- **Styling:** Tailwind CSS
- **Hosting:** Vercel

## Sekcje

- Header z nawigacją i CTA
- Hero – hasło i szybkie statystyki
- Stats – liczby biura
- Services – oferta usług
- WhyUs – wyróżniki biura
- Team – zespół agentów
- Contact – formularz kontaktowy
- Footer

## Deploy

Połącz repo z Vercel – auto-deploy przy każdym pushu do `main`.

## Uruchomienie lokalne

```bash
npm install
npm run dev
```

Otwórz http://localhost:3000
